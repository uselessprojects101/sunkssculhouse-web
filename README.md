# Sonic's Schoolhouse – web port

Browser port of Sega's 1996 PC edutainment game *Sonic's Schoolhouse*.

This repository contains **code only**. You must supply your own copy of the game:
open the page and select the game's `SONIC` folder (or a .zip of it). Files are read
locally in your browser and never uploaded.

## Status
- [x] Asset loader: PCX images, WAV audio
- [ ] SONIC.DAT format
- [ ] MAP / BLK / PRB level data
- [ ] HMI music -> MIDI
- [ ] AVI (8-bit RLE) cutscenes
- [ ] Game logic

Hosted with GitHub Pages.
